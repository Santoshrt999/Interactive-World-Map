# Roadmap

Visual Geography Intelligence is evolving from a geospatial demo into a full open data platform for understanding global challenges.

---

## Phase 1: Launch (May–June 2026)

**Goal:** Ship 3 working dashboards with real data.

- [ ] Climate dashboard — temperature, CO2, renewable energy %
- [ ] Health dashboard — vaccination coverage, life expectancy, healthcare access
- [ ] Humanitarian dashboard — refugees, extreme poverty, active conflicts
- [ ] Data pipeline scripts for automated monthly updates
- [ ] `docs/` folder with CONTRIBUTING, DATA_SOURCES, ROADMAP, API guides
- [ ] Updated README with clear project purpose
- [ ] GitHub issue templates for data requests and feature requests

---

## Phase 2: Depth & Community (July–August 2026)

**Goal:** More data, better UI, first contributors.

- [ ] 2+ additional datasets per dashboard
- [ ] Country comparison tool (side-by-side stats for any 2 countries)
- [ ] Story mode — guided narrative walkthrough of each dashboard
- [ ] Data quality badges on each metric (Official / Aggregated / Estimated)
- [ ] "Why this matters" context tooltips for each metric
- [ ] GitHub Discussions setup for community conversation
- [ ] 3 good-first-issues posted to attract contributors
- [ ] CSV export for any country's data

---

## Phase 3: Integrations & Reach (September–October 2026)

**Goal:** Make the platform embeddable and accessible to more audiences.

- [ ] Embed API — let websites embed individual map panels
- [ ] Social sharing — one-click map screenshot with attribution
- [ ] Mobile responsive improvements
- [ ] Spanish and French translations (UI + story text)
- [ ] Outreach to 5 NGOs and academic institutions
- [ ] First Medium/blog article: "How we built it and why"

---

## Phase 4: Sustainability (November 2026+)

**Goal:** Long-term funding and institutional partnerships.

- [ ] Patreon / OpenCollective for donations
- [ ] Institutional licensing for universities and NGOs
- [ ] Data sponsorship program (organizations fund specific datasets)
- [ ] Academic research partnership (cite in papers)
- [ ] ProductHunt / HackerNews launch
- [ ] Aim for 1,000 GitHub stars

---

## Success Metrics

| Milestone | Target |
|-----------|--------|
| GitHub stars — 1 month | 10–25 |
| GitHub stars — 3 months | 100+ |
| Active contributors | 5+ by month 3 |
| Datasets live | 5+ by launch |
| Monthly visitors | 1,000+ by month 3 |
| Academic / NGO partners | 1+ by month 6 |

---

## Not Planned (yet)

These are out of scope for now — open an issue if you want to champion one:

- Native mobile app
- User accounts / saved views
- Real-time conflict tracking (requires significant infrastructure)
- Paid data sources
